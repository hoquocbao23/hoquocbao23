- 🪑 Table floor plan with area management, three-state item lifecycle (unsent → cooking → served)
- 🖨️ Kitchen ticket printing split by station (kitchen/bar) via local print agent
- 💰 Pricing policy engine: price lists, customer groups, promotions, vouchers, audit logs
- 🔐 JWT authentication with refresh token rotation, account lockout, and rate limiting
- ⚡ Real-time sync across multiple POS terminals
